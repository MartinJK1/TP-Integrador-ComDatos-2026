TP Integrador: Codificación de Datos
Proyecto desarrollado para la cátedra de Comunicaciones de Datos. Incluye implementaciones de Huffman y Shannon-Fano, además de métricas de entropía e información mutua.

Cómo colaborar
Fork: Haz un fork de este repositorio a tu propia cuenta de GitHub.

Clonar: Clona tu fork a tu máquina local (git clone ...).

Rama: Crea una nueva rama para tus cambios (git checkout -b feature/nueva-mejora).

Push: Sube tus cambios a tu repositorio (git push origin feature/nueva-mejora).

Pull Request: Abre un Pull Request desde tu repositorio hacia este repositorio principal para que revisemos tus cambios.
